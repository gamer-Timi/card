# 先后 · 五骰计分

一个以「五颗骰子 + 计分纸」为核心的本地对战游戏。投币决定先后，双方通过固定、暗调与计分展开十一回合的较量。

## 直接开始

打开 `index.html` 即可游戏，无需安装依赖，也无需联网。

- **规则**：查看五骰、固定、暗调、计分纸的完整规则。
- **匹配**：搜索空闲牌桌，并清理长时间无响应的旧房间；没有真人时会提示并进入人机练习。
- **人机练习**：菜单下方可直接单人开局，不必等待匹配。
- **教学**：规则页中的「进入教学」会进入固定剧本教学关。

## 玩法

1. 当前行动方投出 5 颗骰子，并固定 1–3 颗。每方各有一次「固定三颗」的机会。
2. 未固定的骰子中，对方固定获得 2 颗，行动方获得剩余的 2 / 1 / 0 颗。
3. 双方在 60 秒内秘密调整自己分到的骰子（左右箭头 ±1，1 与 6 循环）。
4. 合并五颗骰子，行动方从自己的计分纸中选择一栏填入本次得分。
5. 十一栏全部填完后结算总和。

## 计分栏

- 1–6：对应点数之和
- 葫芦：3 + 2，得 20
- 小顺子：四颗连续，得 20（6 与 1 连续）
- 大顺子：五颗连续，得 30
- 4 条：至少四颗相同，得 20
- 5 条：五颗相同，得 30

**总和不是可填栏目**：它是当前十一栏已填分数的合计，会以另一种颜色显示在纸张下方，不可点击选择。

## 动画

- 骰子投掷参考独立 `dice.html` 的三维骰子造型与翻滚节奏：桌面骰子是六面 CSS 3D 立方体，会从上方翻滚落下并依次回弹；计分面板保留扁平大骰，方便点击固定。
- 开局投币参考独立 `coin.html` 的金属币面和翻转方式：游戏内是双面刻字的 3D 金币，带抛起、旋转和落定；两面分别刻有「先」和「后」，结果直接由落定朝上的那一面决定。
- 两个独立动画页保留为视觉原型，游戏本体不再依赖 iframe，单文件即可离线运行。
- 教学关使用固定骰面，确保剧情与示例稳定。

## 文件

- `index.html`：完整游戏（单文件，离线可玩）
- `dice.html`：独立五骰 3D 掉落动画
- `coin.html`：独立翻硬币动画
- `规则.txt`：原始规则与联机协议记录
- `src-game/`、`build-game.mjs`：游戏源码与构建脚本

## 说明

当前版本的「匹配」会搜索空闲牌桌并清理超过 10 分钟没有更新的房间；如果没有另一名玩家同时在线，会明确提示并转入人机练习。真人双端联机同步尚未接入；核心对局、教学关、计分与 AI 对手均可直接体验。
