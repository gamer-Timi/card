# 先后 · 五骰计分

一个以「五颗骰子 + 计分纸」为核心的本地对战游戏。投币决定先后，双方通过固定、暗调与计分展开十一回合的较量。

## 直接开始

打开 `index.html` 即可游戏，无需安装依赖，也无需联网。

- **规则**：查看五骰、固定、暗调、计分纸的完整规则。
- **匹配**：进入匹配动画，稍后进入一局练习对局。
- **教学**：规则页中的「进入教学」会进入固定剧本教学关。

## 玩法

1. 当前行动方投出 5 颗骰子，并固定 1–3 颗。每方各有一次「固定三颗」的机会。
2. 未固定的骰子中，对方固定获得 2 颗，行动方获得剩余的 2 / 1 / 0 颗。
3. 双方在 60 秒内秘密调整自己分到的骰子（左右箭头 ±1，1 与 6 循环）。
4. 合并五颗骰子，行动方从自己的计分纸中选择一栏填入本次得分。
5. 十一栏全部填完后结算总和。

## 计分栏

- 1–6：对应点数之和
- 葫芦：3 + 2，得 20
- 小顺子：四颗连续，得 20（6 与 1 连续）
- 大顺子：五颗连续，得 30
- 4 条：至少四颗相同，得 20
- 5 条：五颗相同，得 30

**总和不是可填栏目**：它是当前十一栏已填分数的合计，会以另一种颜色显示在纸张下方，不可点击选择。

## 动画

- 骰子投掷接入独立的 `dice.html` 3D 骰子动画，落定后的点数直接用于本回合结算。
- 开局投币接入独立的 `coin.html` 3D 硬币动画，硬币两面分别刻有「先」和「后」，结果直接由落定朝上的那一面决定。
- 教学关使用固定骰面，确保剧情与示例稳定。

## 文件

- `index.html`：完整游戏（单文件，离线可玩）
- `dice.html`：独立五骰 3D 掉落动画
- `coin.html`：独立翻硬币动画
- `规则.txt`：原始规则与联机协议记录
- `src-game/`、`build-game.mjs`：游戏源码与构建脚本
